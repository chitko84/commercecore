# AGENTS.md

This file is a map, not a manual. Do not eagerly read every file below.
Read only what is relevant to your current task.

| Need                | Read                        |
|----------------------|------------------------------|
| Current task          | `NEXT_TASK.md`               |
| Current project state | `PROJECT_STATE.md`           |
| Architecture rules     | `ARCHITECTURE.md`            |
| Product requirements   | `PRODUCT_REQUIREMENTS.md`    |
| Key decisions (ADRs)   | `DECISIONS.md`               |
| Frontend/UI direction  | `docs/UI_DIRECTION.md`       |

Rules for agents working on this repo:

1. Start with `NEXT_TASK.md` for scope, then `PROJECT_STATE.md` for context.
2. Only open other docs/source files that your current task actually touches.
3. Update `PROJECT_STATE.md` and `NEXT_TASK.md` before finishing a session.
4. Keep documentation concise — this repo favors working code over prose.
