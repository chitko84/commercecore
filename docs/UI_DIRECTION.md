# UI_DIRECTION.md

Frontend direction for CommerceCore. This governs Phase 10 (Frontend +
Integration + Testing + Deployment) and any earlier UI prototyping.

## Visual style

- Premium, modern e-commerce design
- Minimal and spacious layouts — generous whitespace, no clutter
- Black / white / neutral surfaces as the base palette
- One bright accent color reserved for primary CTAs (buttons, key
  highlights) — used sparingly, not decoratively
- Large, bold typography for headings and key messaging
- Large product/media sections — let imagery breathe
- Rounded media cards (product images, feature cards, category tiles)
- Minimal shadows/borders — rely on spacing and contrast, not heavy
  elevation

## Layout & responsiveness

- Fully responsive: desktop, tablet, and mobile
- Professional icon set — e.g. Lucide (no emoji-style icons)
- **No emojis in the actual UI**

## Imagery

- Use real, free/licensed images for products, hero sections,
  categories, and features — no stock-look filler that feels fake
- Avoid empty or broken image placeholders
- Approved images should eventually be stored locally with fallbacks
  (don't hotlink indefinitely as the only source)

## Branding

- Do not copy another brand's branding, logos, or exact layouts —
  original composition inspired by best-practice e-commerce UX, not a
  clone of any specific existing store
